# ⚽ Futeboll - Sistema de Gestão de Futebol

Projeto web desenvolvido em PHP para gestão e visualização de informações relacionadas com futebol, incluindo equipas, jogadores, classificações e resultados.

## 🌐 Demo Online

Acede ao projeto aqui:

👉 https://a14702-oficina.infinityfree.me/futeboll/index.php

---

# 📌 Funcionalidades

- ✅ Gestão de equipas
- ✅ Gestão de jogadores
- ✅ Tabela classificativa
- ✅ Resultados de jogos
- ✅ Interface web simples e responsiva
- ✅ Base de dados integrada
- ✅ Sistema desenvolvido em PHP + MySQL

---

# 🛠️ Tecnologias Utilizadas

- **PHP**
- **MySQL**
- **HTML5**
- **CSS3**
- **JavaScript**
- **Bootstrap** (se aplicável)
